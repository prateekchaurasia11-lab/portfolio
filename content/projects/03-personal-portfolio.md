### The challenge

A personal portfolio needs to present skills, projects, and contact details clearly on both mobile and desktop screens.

### The approach

- Designed a fully responsive personal portfolio with modular UI components.
- Built navigation patterns that make the site easy to move through.
- Optimized layout for cross-device compatibility.
- Improved load speed and user retention through cleaner structure.
