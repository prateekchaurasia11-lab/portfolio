# Prateek Chaurasiya Portfolio

Personal portfolio for Prateek Chaurasiya, an Information Technology student and web developer focused on React applications, AI workflows, REST APIs, and thoughtful web experiences.

## Highlights

- Profile, resume, projects, and leadership experience in one responsive portfolio.
- Markdown-powered project, experience, and education content.
- Contact form delivered through FormSubmit.
- Custom visual system built with Tailwind CSS.

## Tech Stack

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Vite and Tailwind CSS 4
- Content Collections and Markdown
- FormSubmit

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production Build

```bash
npm run build
```

The production output is created in `dist`.

## Project Structure

- `src/routes` contains the portfolio pages and routing.
- `src/styles.css` contains the global visual system and responsive styling.
- `content/projects` stores project case studies.
- `content/jobs` stores experience and leadership entries.
- `content/education` stores education information.
- `public` contains static portfolio assets.

## Contact

The contact page submits messages through FormSubmit to Prateek's inbox.
