# Prateek Chaurasiya Portfolio

A personal portfolio for Prateek Chaurasiya, an Information Technology student and web developer focused on React, AI workflows, REST APIs, and web deployment.

## Technology

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Tailwind CSS 4 with custom global styling
- Content Collections for typed Markdown projects and resume entries
- FormSubmit for contact messages

## Local development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

The default Vite development URL is `http://localhost:3000`.

## Content

Portfolio projects live in `content/projects`, leadership entries in `content/jobs`, and education in `content/education`.

The React contact form sends messages through FormSubmit.
